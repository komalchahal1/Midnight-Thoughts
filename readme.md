
# 🌙 Midnight Thoughts

A modern dark aesthetic journaling app built using only:

- HTML
- CSS
- JavaScript

“Midnight Thoughts” is a beginner-friendly thought saving app where users can write and store their thoughts with a premium glassmorphism dark UI.


# ✨ Features

- Dark mode aesthetic UI
- Purple & blue glowing effects
- Smooth animations
- Glassmorphism design
- Responsive for mobile & desktop
- Save thoughts instantly
- Delete saved thoughts
- LocalStorage support
- Thoughts remain after refresh
- Empty state message
- Smooth hover animations
- Beautiful modern typography
