
# 🌙 Midnight Thoughts

Midnight Thoughts is a modern dark aesthetic journaling app designed for people who love writing late-night thoughts, emotions, and memories in a calm relaxing environment.

Built using only:
- HTML
- CSS
- JavaScript

The app features glowing UI effects, animated backgrounds, lofi music, password protection, mood tracking, and a premium glassmorphism design.

# ✨ Features

## 🌙 Core Features
- Save thoughts instantly
- Delete thoughts
- Edit thoughts
- LocalStorage support
- Thoughts remain saved after refresh
- Real-time feedback messages
- Empty state UI


# 🔒 Privacy Features
- Password lock screen
- Create your own password
- Private journal experience


# 🎵 Music Features
- Built-in lofi music support
- Play / Pause music control
- Floating aesthetic music card


# 😊 Mood System
Choose moods while saving thoughts:
- 🌙 Normal
- 😊 Happy
- 😔 Sad
- 🌧 Lonely

Thought cards glow differently based on mood.


# ✨ UI & Design
- Dark aesthetic interface
- Purple & blue neon glow effects
- Glassmorphism cards
- Animated stars background
- Floating blurred circles
- Smooth hover effects
- Responsive mobile-first design
- Premium modern journaling vibe


# 📱 Responsive Design
Works beautifully on:
- Mobile devices
- Tablets
- Desktop screens


# 💾 LocalStorage
This app uses browser LocalStorage to:
- Save thoughts permanently
- Save password locally
- Keep user data after refresh

No database required.
